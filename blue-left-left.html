The Java that builds it

// leg 1 → path1
Paths.line(start, path1).linear(start, path1)
// leg 2 → point2
Paths.line(path1, point2).linear(path1, point2)
// leg 3 → point3
Paths.curve(point2, point3Control1, point3).linear(point2, point3)
// leg 4 → point4
Paths.line(point3, point4).linear(point3, point4)
// leg 5 → point5
Paths.line(point4, point5).linear(point4, point5)
// leg 6 → park
Paths.line(from, park).constant(from.heading())

Park is not a fixed final leg. The OpMode checks every loop whether the time left is only just enough to reach the park spot, and if so it abandons the route and drives there from wherever it is. The park leg drawn above is the normal end-of-route case.
